Task 7 — Perform Data Analysis

Objective:
Perform analysis on the customer_analytics table to gain insights into customer churn and its impact on revenue.

Analysis Outputs & SQL Scripts:

1. Churn Rate Across All Customers
-- Calculate the percentage of churned customers
SELECT 
    ROUND(100.0 * SUM(CASE WHEN customer_status = 'Churned' THEN 1 ELSE 0 END) / COUNT(*), 2) AS churn_rate_percentage
FROM customer_analytics;

2. Top Cities with Highest Number of Churned Customers
-- Identify cities with the most churned customers
SELECT 
    city,
    COUNT(*) AS churned_customers
FROM customer_analytics
WHERE customer_status = 'Churned'
GROUP BY city
ORDER BY churned_customers DESC
LIMIT 10;

3. Customer Churn Distribution by Tenure Group
-- Group customers by tenure ranges and count churned customers
SELECT 
    CASE 
        WHEN tenure::INT BETWEEN 0 AND 12 THEN '0-12 months'
        WHEN tenure::INT BETWEEN 13 AND 24 THEN '13-24 months'
        WHEN tenure::INT BETWEEN 25 AND 36 THEN '25-36 months'
        ELSE '36+ months'
    END AS tenure_group,
    COUNT(*) AS churned_customers
FROM customer_analytics
WHERE customer_status = 'Churned'
GROUP BY tenure_group
ORDER BY tenure_group;

4. Total Revenue Lost Due to Churn
-- Sum the total charges of churned customers
SELECT 
    SUM(CASE WHEN total_charges IS NOT NULL THEN total_charges::DECIMAL ELSE 0 END) AS total_revenue_lost
FROM customer_analytics
WHERE customer_status = 'Churned';

5. Population vs Customer Count by Zip Code
-- Compare population vs number of customers in each zip code
SELECT 
    zip_code,
    population,
    COUNT(customer_id) AS customer_count
FROM customer_analytics
GROUP BY zip_code, population
ORDER BY customer_count DESC;

Notes:
- Ensure numeric columns like tenure, monthly_charges, and total_charges are cast appropriately for calculations.
- Use these SQL scripts to generate insights directly in Redshift Serverless.
- Results can be exported to CSV or visualized using BI tools for further analysis.
