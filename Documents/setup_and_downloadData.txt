Customer Churn Analytics Warehouse using Amazon Redshift

Task 1 — Download Dataset

Objective
The objective of this task is to download the telecom customer churn dataset from Kaggle and prepare it for further processing in Amazon S3 and Amazon Redshift.

Dataset Source

Dataset:
https://www.kaggle.com/datasets/shilongzhuang/telecom-customer-churn-by-maven-analytics

The dataset used in this project is obtained from Kaggle. The dataset is titled “Telecom Customer Churn by Maven Analytics” and contains customer information from a telecom company that will be used to analyze customer churn patterns.

Dataset Description
The dataset consists of two CSV files.

1. telecom_customer_churn.csv
This file contains detailed information about telecom customers including customer ID, gender, age, city, zip code, tenure, monthly charges, total charges, and customer status (churned or stayed). The file contains 7,043 customer records.

2. telecom_zipcode_population.csv
This file contains population information for zip codes in California. The file includes zip code and population columns. This dataset will be used later to analyze customer distribution based on population.

Steps Performed
Step 1: Open the Kaggle website in a browser.
Step 2: Search for the dataset “Telecom Customer Churn by Maven Analytics”.
Step 3: Click on the download button and download the dataset as a ZIP file.
Step 4: Extract the downloaded ZIP file.

Extracted Files
After extracting the ZIP file, the following files were obtained:

telecom_customer_churn.csv
telecom_zipcode_population.csv

The extracted files were stored in the following folder:

Outcome of Task 1
The telecom customer churn dataset was successfully downloaded from Kaggle and extracted. The required CSV files are now ready to be uploaded to Amazon S3 in the next task.
